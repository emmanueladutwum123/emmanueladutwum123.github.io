Research Context: Ghana Cocoa Market

This simulator supports research on option pricing models for hedging cocoa price risk in Ghana. Ghana produces 40% of global cocoa, but local stakeholders lack accessible derivative instruments. This tool demonstrates how European-style options can be priced and hedged using the Black-Scholes model, with applications for the Ghana Commodity Exchange (GCX).

Black-Scholes Formula:

For Call: C = S₀N(d₁) - Ke⁻ʳᵀN(d₂)

For Put: P = Ke⁻ʳᵀN(-d₂) - S₀N(-d₁)

where: d₁ = [ln(S₀/K) + (r + σ²/2)T] / (σ√T), d₂ = d₁ - σ√T

Delta Hedging Strategy:

1. Sell 1 option contract (receive premium)

2. Buy Δ shares of underlying to hedge

3. Rebalance portfolio as Δ changes

4. At maturity: Option payoff + hedge position = ~0
